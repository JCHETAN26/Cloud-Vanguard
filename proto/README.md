# proto

Shared protocol definitions.

| File | Purpose |
|---|---|
| `vanguard/control/v1/control.proto` | Control plane: `RingConfig` (peer ring topology), `TenantPolicySet` (dynamic tenant limits / semantic mode / threshold / TTL / API-key hashes), `ControlDocument` (both), `ApplyResult`, and the `ControlPlane` service. |

**Encodings:**
- **Go operator:** uses types generated by `protoc-gen-go` (`operator-go/internal/controlpb`, via `make proto`
  in `operator-go/`).
- **C++ proxy:** speaks the proto3 canonical JSON mapping on its admin listener and in `CONTROL_FILE`
  (`proxy-cpp/src/control.cpp`), so it doesn't need a protobuf runtime.
- **Contract test:** the Go golden file `operator-go/internal/render/testdata/control_golden.json` is parsed by
  the C++ test `ControlPlaneGolden.AcceptsTheOperatorsRenderedDocument`.

**Endpoints (admin port, default 9901, `Authorization: Bearer <ADMIN_TOKEN>`):**

```
PUT /admin/v1/ring      RingConfig       -> ApplyResult
PUT /admin/v1/tenants   TenantPolicySet  -> ApplyResult
PUT /admin/v1/config    ControlDocument  -> ApplyResult
GET /admin/v1/config                     -> ControlDocument
```

**Version rules:** a higher version is applied; the same version is a no-op (200, `applied=false`); a lower
version is stale (409); version 0 is a manual override.

Peer CSI messages (Phase 6) will live under `vanguard/csi/`.
